# Pulse — Expense Tracker

A frontend-only expense tracker / budget planner built with plain HTML, CSS and JavaScript.

## Included requirements
- Add, edit and delete income/expense transactions
- Category + account tagging
- Monthly budgets with progress / over-budget states
- Expense analytics with donut + trend charts
- Recurring payment reminders and "Mark paid"
- Multi-account tracking
- Saving goals with progress
- Search, filtering and sorting
- CSV export and JSON backup
- LocalStorage persistence
- Responsive mobile layout
- Smooth dark fintech UI using the supplied reference palette
- Notifications panel and toast feedback

## Run
Open `index.html` directly in a modern browser.

No backend or build step is required.

## Notes
The app stores its demo data in browser LocalStorage under:
`pulse-expense-tracker-v1`

Use "Reset demo" in the sidebar to restore the original sample data.
